# Suryarochih Samaddar · Portfolio

## Deploying to GitHub Pages

1. Create a new GitHub repo named: `yourusername.github.io` (set to **Public**)
2. Upload ALL files — keep the folder structure exactly as-is
3. Go to **Settings → Pages → Source: main branch → Save**
4. Live at: `https://yourusername.github.io` (takes ~2 min to propagate)

## Folder Structure

```
portfolio/
├── index.html          ← All content (edit this file)
├── style.css           ← All styling & theme variables
├── script.js           ← Navigation, carousel, search, guestbook
├── charts.js           ← Chart.js animated charts
├── README.md           ← This file
└── assets/
    ├── resume.pdf      ← Your resume (replace with updated version)
    └── images/
```

## To update content

- **Text / sections**: edit `index.html` directly
- **Styles / colours**: edit `style.css`
- **Charts**: edit `charts.js`
- **Resume**: replace `assets/resume.pdf`
- **Photos**: replace images in `assets/images/`

## Colour themes

- **Light mode**: Lavender / White / Mauve Purple
- **Dark mode**: Black / Dark Green / Lime (toggle via 🌙 button)
